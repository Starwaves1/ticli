# ticli — agent entry points

**Using ticli** (searching TIDAL, resolving songs, managing playlists, checking
the player): run `ticli agent docs`. It is the whole contract. Don't import
ticli's internals or call TIDAL's API directly; see
[ADR-0001](docs/adr/0001-tidal-rate-limits.md) for why.

**Working on ticli's code**: read [`CLAUDE.md`](CLAUDE.md).
